# Galería de trabajos del Playground

Capturas y archivos de imagen conservados de los trabajos existentes, organizados para abrir desde el teléfono. Cada página muestra hasta 24 imágenes; pulsar una permite consultar el archivo original.

Ocean Lab está excluido. Las fechas, fuentes y hashes están en [provenance.json](provenance.json). Esta galería combina tandas actuales e históricas: las notas de cada familia indican sus límites; publicar una imagen no declara terminado el sistema.
