# Task 21 cliff-wall geology target

Date: 2026-08-26

The visual target is a close view of one continuous cave/cliff wall.  The wall
continues beyond the Beauty frame; several rock masses remain embedded in it
and project toward the viewer.  It is not a freestanding noisy box.
