# Paused per-fiber and cohesive physics research

EXPERIMENTAL WIP. Preserved at the scope change to inexpensive whole-panel removal. This source snapshot is not a completed game feature and is not linked into the later whole-panel impact prototype.

The strand solver and individual modules had focused passing tests, while integrated carrier tearing and deformation quality were not accepted as a whole. Cohesion materially improved the observed low-load carrier shape. The last cohesive_binding.cpp integration was only syntax-checked; complete runtime acceptance was not run after that edit. UV cage mapping still has a small number of folded triangles, and local tears are not fully wired into the CLI. Do not present these sources as all-green or production-ready.

The expensive 16x12 solver configuration was an offline research profile, not a realtime claim. Biological silk calibration, general collision integration, Jolt, self-collision and editor UI are absent. The conservative recursive carrier-erasure attempt destroyed the full graph and was rejected. The bending probe did not solve the visual transfer issue.

Included projects retain their respective headers, implementation, tests, scripts and recipes. No rendered binaries, private input references, access tokens or Library IDs are part of this snapshot. Previously delivered visuals are preserved separately.
