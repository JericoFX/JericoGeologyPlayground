§22 failing fixture: the former `pathSegmentMesh` extruded a fixed-radius capsule with straight side walls. The shared backend now uses that bounded profile for the edge and shared structured noise for a depth-varying sheet. The field query and geometric cutter use one outline function. This is preferable to adding rock-only noise; it is also usable on selected wooden members. The geometry stays bounded by the existing mesh budget and requires a through-fracture before chunk separation.

The UI exposes irregularity and separation; seed and editable path are retained. A nonpenetrating cut with separation is rejected rather than pretending to make two pieces.
